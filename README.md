# BlockDAG Phoenix Organization Files

This repository contains organization-wide community health files for BlockDAG Phoenix.

## Files

- `profile/README.md` - Organization profile README (shown on org homepage)
- `CODE_OF_CONDUCT.md` - Code of conduct for contributors
- `CONTRIBUTING.md` - Contribution guidelines
- `SUPPORT.md` - Where to get help
- `SECURITY.md` - Security policy
- `ISSUE_TEMPLATE/` - Issue templates for bug reports and feature requests
- `pull_request_template.md` - Pull request template

## How It Works

GitHub automatically uses these files across all repositories in the BlockDAGPhoenix organization. Individual repositories can override these with their own versions if needed.

## Updating

To update organization-wide files:

1. Make changes in this repository
2. Submit a pull request
3. Once merged, changes apply to all repositories
